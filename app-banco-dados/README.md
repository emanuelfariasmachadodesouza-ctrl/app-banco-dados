# Aplicação integrada a banco de dados

Exemplo de portfólio: CRUD (cadastrar, consultar, editar e excluir) em React + TypeScript. Sem banco externo: os dados ficam no `localStorage` do navegador.

## Rodar local
```
npm install
npm run dev
```

## Deploy na Vercel
Suba para o GitHub e importe na Vercel (Vite é detectado automaticamente, sem variáveis).
